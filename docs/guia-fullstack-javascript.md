# Guía de estudio fullstack JavaScript/TypeScript

Recomendada para desarrolladores con experiencia intermedia en JavaScript que
quieren avanzar hacia un perfil fullstack moderno, dominando tanto backend como
frontend con las tecnologías más relevantes en 2025.

Recomendaciones basadas en los siguientes libros:

- Advanced JavaScript Unleashed (2024) by John Doe
- Fullstack Node.js (2019) by Jane Smith
- Fullstack React with TypeScript (2020) by Alice Johnson
- Fullstack GraphQL (2020) by Bob Brown
- Fullstack Data Visualization with D3 (2019) by Carol White
- JavaScript Algorithms (2019) by David Green
- Fullstack React (2017) by Emily Black
- Fullstack Vue (2018) by Frank Blue
- Documentación oficial de
  [React](https://es.react.dev/?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation),
  [TypeScript](https://www.typescriptlang.org/docs/?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation),
  [Node.js](https://nodejs.org/es/docs/?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)
  y
  [GraphQL](https://graphql.org/learn/?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)

## Principios de la guía

- Aprendizaje activo: Cada fase incluye retos y proyectos prácticos para aplicar
  lo aprendido.
- Progresión clara: El avance es gradual, desde fundamentos avanzados de JS
  hasta proyectos fullstack completos.
- Bibliografía aplicada: Cada libro se traduce en ejercicios y proyectos
  concretos, no solo teoría.
- Portfolio real: Al finalizar, tendrás varios proyectos documentados en GitHub,
  listos para mostrar.

## 🧭 Orden de lectura recomendado

1. [Advanced JavaScript Unleashed (2024)](https://www.newline.co/courses/advanced-javascript-unleashed?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)

👉 Punto de partida.

📘 Por qué: Este libro te va a permitir cerrar brechas conceptuales y entender
el lenguaje a nivel de motor. Cubre temas como prototipos, closures, symbols,
iteradores, generadores, metaprogramación y el event loop —justo lo que
diferencia a un desarrollador intermedio de uno avanzado.

🎯 Objetivo: Convertirte en un experto en el lenguaje base (JS) para que el
resto de tecnologías te resulten naturales. 💡 Enfoque: Estudia con ejemplos
prácticos y prueba cada concepto en un mini repositorio sandbox (Node + browser
console).

---

2. [Fullstack Node.js (2019)](https://www.newline.co/fullstack-nodejs?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)

👉 Fundamentos sólidos del backend moderno.

📘 Por qué: Este libro te ayudará a dominar el entorno de ejecución y la
arquitectura de backend con Node.js, Express, manejo de bases de datos
(MongoDB), autenticación, middlewares, y prácticas de producción.

🎯 Objetivo: Construir servidores eficientes, seguros y escalables. 💡 Consejo:
Complementa con documentación moderna (Node 18+ y Express 5) y buenas prácticas
de despliegue (Docker, PM2 o Bun).

---

3. [Fullstack React with TypeScript (2020)](https://www.newline.co/fullstack-react-with-typescript?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)

👉 Tu paso natural hacia el frontend moderno.

📘 Por qué: Te introduce a React Hooks, Redux, SSR y GraphQL con TypeScript,
justo las tecnologías que quieres dominar. Aprenderás patrones de arquitectura,
testing y tipado estático aplicado al frontend real.

🎯 Objetivo: Crear interfaces modulares, tipadas y mantenibles con React. 💡
Enfoque: Practica reescribiendo tus pequeños proyectos en React usando
TypeScript y herramientas modernas como Vite o Next.js.

---

4. [Fullstack GraphQL (2020)](https://www.newline.co/fullstack-graphql?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)

👉 Conecta frontend y backend de forma moderna.

📘 Por qué: GraphQL es clave en APIs modernas. Este libro te enseña cómo diseñar
esquemas, resolver queries y mutations, y conectar clientes React o Node.
Además, al venir después de los dos anteriores, ya tendrás las bases para
comprenderlo de forma integral.

🎯 Objetivo: Crear APIs robustas con GraphQL y consumirlas eficientemente desde
frontend y backend. 💡 Enfoque: Implementa una API GraphQL sobre tu backend
Node, y consúmela con React o Apollo Client.

---

5. [Fullstack Data Visualization with D3 (2019)](https://www.newline.co/fullstack-d3?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)

👉 Para destacar visualmente tus aplicaciones.

📘 Por qué: D3 te da una comprensión profunda de cómo manipular el DOM con
datos, lo que fortalece tu pensamiento visual y te será útil si haces dashboards
o analíticas.

🎯 Objetivo: Aprender a transformar datos en visualizaciones ricas e
interactivas. 💡 Enfoque: Aplícalo sobre tus proyectos de GraphQL o APIs
públicas.

---

6. [JavaScript Algorithms (2019)](https://www.newline.co/javascript-algorithms?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)

👉 Consolidación técnica y mejora de pensamiento lógico.

📘 Por qué: Este libro refuerza el dominio de estructuras de datos y algoritmos
con ejemplos en JavaScript moderno. Te ayuda a escribir código más eficiente y
comprender la optimización en proyectos grandes.

🎯 Objetivo: Mejorar la eficiencia, claridad y rendimiento de tu código. 💡
Enfoque: Implementa los algoritmos en TypeScript y crea tus propias utilidades.

---

7. [Fullstack React (2017)](https://www.newline.co/fullstack-react?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)
   y
   [Fullstack Vue (2018)](https://www.newline.co/vue?utm_source=github&utm_medium=lgzarturo&utm_campaign=book_recommendation)

👉 Referencias prácticas complementarias.

📘 Por qué: Aunque algo desactualizados, ambos libros siguen siendo buenos para
entender los fundamentos arquitectónicos de React y Vue. Puedes usarlos como
material de referencia o repaso una vez domines React con TypeScript.

🎯 Objetivo: Ampliar tu visión de frameworks frontend. 💡 Enfoque: Toma las
ideas que siguen siendo válidas (componentización, flujo de datos, ciclo de
vida).

## 📅 Plan de estudio sugerido

- Duración estimada: 24 semanas (6 meses)
- Modalidad sugerida: ~8–10 horas semanales entre lectura, práctica y mini
  proyectos.
- Organizada por fases (con enfoque progresivo y proyectos aplicados).
- Cada fase incluye retos, práctica continua y un proyecto factible.
- Al finalizar, tendrás un portfolio profesional y dominio fullstack moderno.

> El objetivo es avanzar de forma estructurada, pero adaptando el ritmo según tu
> disponibilidad y comprensión de los temas. La idea es estudia máximo 2 horas
> diarias, 4 días a la semana, para evitar agotamiento.

### 🧠 Fase 1: Dominio avanzado de JavaScript

Duración: 4 semanas Libro base: Advanced JavaScript Unleashed (2024) Objetivo:
JavaScript avanzado y fundamentos profundos - Comprender a fondo el lenguaje
(prototipos, closures, async/await, event loop, metaprogramación, etc.)
Tecnologías: Node.js (modo consola) + navegador.

#### Aprendizajes clave fase 1

- Configurar entorno de práctica (Node + VSCode + ESLint + Prettier).
- Crear repositorio advanced-js-lab.
- Leer y practicar 2–3 capítulos por semana del libro.
- Documentar ejemplos y descubrimientos con comentarios.

#### 🗓 Semana 1: Fundamentos profundos

- Revisar diferencias entre var, let, const.
- Practicar closures y scope chain.
- Entender cómo funciona this en distintos contextos.
- 🧩 Proyecto: “Scope Visualizer” — script que imprime ejemplos con comentarios.

#### 🗓 Semana 2: Asincronía y Event Loop

- Repasar promises, async/await y microtasks/macrotasks.
- Practicar con setTimeout, fetch, y Promise.all().
- 🧩 Proyecto: “API Fetcher” con reintentos automáticos y delays configurables.

#### 🗓 Semana 3: Iteradores, Generadores y Symbols

- Implementar un custom iterator y un generator function.
- Entender usos prácticos de Symbol.iterator.
- 🧩 Proyecto: “Iterable Collection” que soporta for...of personalizado.

#### 🗓 Semana 4: Metaprogramación

- Aprender Proxy y Reflect.
- Crear un ejemplo de interceptación de propiedades.
- 🧩 Proyecto: “Reactive Object” (mini reactividad).

#### 📚 Retos fase 1

1. Crea un archivo interactivo que demuestre cada concepto.
2. Asincronía (Promises, async/await, Event Loop): Crea un script que consuma
   una API con retry y timeout.
3. Symbols, Iterators, Generators: Implementa una colección iterable
   personalizada.
4. Proxy, Reflect, metaprogramación: Crea una mini reactividad al estilo Vue 2
   usando Proxy.
5. Implementa closures, scope chain y visualiza el comportamiento de this.
6. Crea iteradores y generadores personalizados.
7. Aplica metaprogramación con Proxy y Reflect.

#### Proyecto propuesto: Advanced JS Lab

Repositorio con scripts que demuestran cada concepto avanzado, incluyendo:

- Visualizador de scope y closures.
- API Fetcher con reintentos y delays configurables.
- Colección iterable personalizada.
- Mini sistema reactivo con Proxy.
- Documenta cada descubrimiento con comentarios y ejemplos.
- Realiza mini pruebas unitarias para cada script.

### ⚙️ Fase 2: Backend sólido con Node.js

Duración: 5 semanas Libro base: Fullstack Node.js (2019) Objetivo: Construir
APIs REST seguras, modulares y listas para producción. Stack: Node.js,
Express.js, MongoDB, JWT, Docker (opcional)

#### Aprendizajes clave fase 2

- Crear proyecto task-manager-api con Express y TypeScript.
- Configurar ESLint, Nodemon, y testing básico con Jest.
- Conectar a MongoDB (local o Atlas).

#### 🗓 Semana 5

- Entender estructura de módulos y separación por capas (routes, controllers,
  services).
- 🧩 Proyecto: “Task CRUD” con endpoints básicos.

#### 🗓 Semana 6

- Implementar middlewares globales (logging, validaciones, errores).
- Usar express-validator o zod para sanitizar inputs.

#### 🗓 Semana 7

- Implementar autenticación con JWT.
- Crear endpoints protegidos según rol.
- Añadir rate-limiting y CORS.

#### 🗓 Semana 8

- Conectar a MongoDB usando Mongoose.
- Crear modelos User y Task con relaciones básicas.

#### 🗓 Semana 9

- Escribir pruebas unitarias y de integración con Jest/Supertest.
- Preparar un Dockerfile.
- Desplegar la API en Railway, Render o AWS.

#### 📚 Retos fase 2

1. Arquitectura y módulos: API básica con CRUD y rutas modulares.
2. Middleware, validaciones, errores: Añade middlewares globales y validadores
   con Joi o Zod.
3. Autenticación (JWT, roles): Extiende la API para manejar usuarios y roles.
4. Persistencia con MongoDB: Integra Mongoose y crea un modelo de datos robusto.
5. Tests y despliegue: Escribe tests con Jest y despliega en Docker o Railway.
6. Construye una API REST modular con Express y TypeScript.
7. Implementa middlewares globales, validaciones y manejo de errores.
8. Añade autenticación JWT y roles.
9. Conecta a MongoDB y realiza operaciones CRUD.

#### Proyecto propuesto: Task Manager API

API completa para gestión de tareas, con:

- Endpoints protegidos y roles de usuario.
- Validaciones con Zod/Joi.
- Pruebas unitarias con Jest/Supertest.
- Dockerfile y despliegue en Railway/Render.
- Refactoriza el código tras cada capítulo.
- Documenta endpoints y flujos de autenticación.

### 💻 Fase 3: Frontend moderno con React + TypeScript

Duración: 5 semanas Libro base: Fullstack React with TypeScript (2020) Objetivo:
Aprender patrones profesionales en React con tipado estático. Stack: React,
TypeScript, Vite, Redux Toolkit, React Router.

#### Aprendizajes clave fase 3

- Crear proyecto react-ts-dashboard con Vite o Next.js.
- Configurar TypeScript, ESLint, Prettier, y Testing Library.

#### 🗓 Semana 10

- Revisar fundamentos de TS en React (props, estados, tipos genéricos).
- 🧩 Proyecto: “UI Kit” con botones, inputs y modales reutilizables.

#### 🗓 Semana 11

- Profundizar en Hooks (useReducer, useMemo, useCallback).
- 🧩 Proyecto: “Todo App” usando Context API.

#### 🗓 Semana 12

- Introducir Redux Toolkit + RTK Query.
- Escribir pruebas unitarias de reducers.
- 🧩 Proyecto: “Todo App Pro” (estado global + tests).

#### 🗓 Semana 13

- Implementar SSR básico con Next.js.
- Crear rutas dinámicas y páginas protegidas.
- 🧩 Proyecto: “Blog SSR” con autenticación.

#### 🗓 Semana 14

- Conectar tu frontend con task-manager-api.
- Manejar sesiones y errores del backend.
- 🧩 Proyecto: “Task Dashboard” (frontend+backend completo).

#### 📚 Retos fase 3

1. TypeScript y componentes funcionales: “UI Components”: Crea un pequeño design
   system (botones, inputs, modales).
2. Hooks y contexto: “Todo App”: App con estado global usando Context + Reducer.
3. Redux y testing: “Todo App Pro”: Refactoriza usando Redux Toolkit y Jest.
4. SSR, Routing avanzado: “Blog SSR”: App con routing, fetching y SSR con Vite o
   Next.js.
5. Integración con API: “Dashboard”: Consume la API Node.js creada en la Fase 2.
6. Crea componentes funcionales y tipados.
7. Implementa estado global con Context API y Redux Toolkit.
8. Añade pruebas unitarias y de integración.
9. Conecta el frontend con la API creada en la fase anterior.

#### Proyecto propuesto: Task Dashboard

SPA para gestionar tareas, con:

- UI Kit de componentes reutilizables.
- Estado global y manejo de sesiones.
- Integración con la Task Manager API.
- Pruebas con Testing Library.
- Reescribe componentes usando diferentes patrones.
- Documenta decisiones de arquitectura y tipado.

### 🔗 Fase 4: GraphQL Fullstack

Duración: 4 semanas Libro base: Fullstack GraphQL (2020) Objetivo: Integrar
GraphQL como capa moderna de comunicación entre frontend y backend. Stack:
Node.js (Apollo Server), React (Apollo Client), TypeScript.

#### Aprendizajes clave fase 4

- Crear proyecto graphql-task-dashboard.
- Reutilizar modelos y lógica del task-manager-api.

#### 🗓 Semana 15

- Crear esquema (typeDefs) con tipos User, Task.
- Instalar Apollo Server y levantar el endpoint /graphql.

#### 🗓 Semana 16

- Implementar resolvers (queries, mutations, relaciones).
- Añadir validaciones y paginación.

#### 🗓 Semana 17

- Integrar Apollo Client en React.
- Crear hooks personalizados (useTasksQuery, useAddTaskMutation).

#### 🗓 Semana 18

- Implementar autenticación con context en Apollo.
- Añadir subscripciones para actualizaciones en tiempo real.

#### 📚 Retos fase 4

1. Fundamentos y esquemas: Define un esquema GraphQL sobre tu API (User, Tasks).
2. Queries y mutations: Implementa resolvers y operaciones CRUD.
3. Integración con React: Consume la API desde React con Apollo Client.
4. Autenticación y seguridad: Añade JWT y manejo de contexto de usuario.
5. Diseña esquemas GraphQL robustos.
6. Implementa resolvers, queries y mutations.
7. Integra Apollo Server y Apollo Client.
8. Añade autenticación y subscripciones en tiempo real.

#### Proyecto propuesto: GraphQL Task Dashboard

App fullstack con:

- API GraphQL sobre la Task Manager API.
- Cliente React con Apollo Client.
- Subscripciones para actualizaciones en tiempo real.
- Documenta el esquema y los resolvers.
- Realiza pruebas de queries y mutations.
